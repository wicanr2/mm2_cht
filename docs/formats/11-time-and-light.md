# 時間與照明

MM2 的時間單位是**步**。走一步呼叫 root `0x150CE`，那一支同時管四件事：
照明消耗、日內時鐘、日期與年份、隊員年齡。

```
step(n):                                   ; root 0x150CE，n = 步數
    if n == 1 && (ds:59C8 & 0x20) && ds:03D5 != 0:
        dec ds:03D5                        ; 站在吃照明的格子上，燒一點
        重畫狀態列
    ds:03CC += n                           ; 今天走了幾步
    if ds:03CC >= 0x100:
        day = ++日期表[索引]                ; ds:03A2 + ds:03CA×2
        ds:03CC %= 0x100
        sub_15092()                        ; 每個隊員的年齡加一天
        if day 是 60／120／180: ds:03F4 = ds:03F5 = 0
        if 日期表[索引] > 180:
            日期表[索引] = 1
            年份表[索引]++（到 999 為止）    ; ds:03B6 + ds:03CA×2
            ds:03EA = 0
```

**256 步一天、180 天一年、年份上限 999。** 日期與年份都是**十格的表**，
由 `ds:03CA` 選一格；畫面上的 `Day=`／`Year=` 是索引 9 那一格
（`ds:03B4` 與 `ds:03C8`）。

年齡在角色記錄裡佔兩個位元組：`+0x21` 是歲、`+0x22` 是今年的第幾天。
`sub_15092` 逐一把 `+0x22` 加一，滿 181 就 `+0x21` 加一並歸 1
—— 與地圖上的 180 天一年一致。

`ds:03F4`／`ds:03F5`（每 60 天）與 `ds:03EA`（每年）被清掉，用途未解。

## 日內時鐘沒有人讀

`ds:03CC` 是一個貨真價實的日內時鐘（0–255），但**原版的繪圖路徑一處都
沒讀它** —— `ds:03CA`–`ds:03CE` 的全部使用點掃過，只有上面那一支在動它。
所以 **MM2 的 DOS 版沒有日夜**：天數會累積，畫面不會變。

remake 的「入夜視野變暗」是 `F2` 裡的選項、**預設關**：時鐘是 DOS 的，
變暗的做法借自 Mega Drive（整條調色盤 `分量 × 亮度 ÷ 8`，晝 8、夜 6），
而「一天的後半算夜晚」是 remake 挑的，不是量到的。見
[`polish-spec`](../polish-spec.md)。

## 照明

`ds:03D5` 是照明計數：照明術 `+1`（上限 254）、持續照明術一次 `+20`
（上限 235），與 `ds:03D5`–`ds:03E1` 那一段旅行效果一起被換圖與休息清掉
（`2MISC sub_1CD8A`）。它有兩個消費端：

1. **走在吃照明的格子上**，一步燒一點（上面那一支）。
2. **畫第一人稱之前**（`sub_13FFC`）：

```
ds:39E = 0
if ds:03D5 == 0 && (ds:59A0 >= 0x80 || (ds:59C8 & 0x20)):
    ds:39E = 1
if ds:39E != 0:
    清掉視窗 8                              ; 文字格 (1,1) 起 26×15
    游標到文字格 (10,8)，印 ds:4DFB          ; "Darkness"
    return                                  ; ← 第一人稱整塊不畫
```

**不是調暗，是不畫。** 視窗 8 的矩形（文字格 (1,1) 起 26×15）換算成像素
是 (8,8)–(216,128)，剛好就是第一人稱視圖那一塊；`Darkness` 八個字
× 8 px 從 x=80 起，在那塊裡正好置中。

兩個「這裡是暗的」的來源：

| 旗標 | 位置 | 意思 | 資料量 |
|---|---|---|---|
| `ATTRIB +26` 的 bit 7 | 整張圖 | 這張圖沒有光源 | 13 張，全在 17–32（地城）|
| 屬性層的 bit 5 | 單一格 | 這一格吃照明 | 125 格、6 張圖（2、4、17、22、58、59）|

`+26` 那個位元組其餘的位元是法術禁令（見
[`09-spells`](09-spells.md)）；bit 7 與法術無關。

> **掃「誰讀這個位址」要連 root 一起掃，而且要掃位移不是字面。**
> overlay 裡 IDA 把當前格的快取命名成 `byte_159C8`，root 裡沒有名字、
> 寫成 `ds:59C8h` —— 只比對前者的掃描會漏掉 root 那兩條，
> 而漏掉的長相與「沒有人讀」一模一樣。屬性層 bit 5 因此被寫成
> 「原版沒有任何一處讀它」很久，見 `CONTEXT.md` §5。
