# 法術系統

## 1. 一套編號貫穿三處

`SPELLS.DAT`、`2CAST1.OVL` 與 `2CAST2.OVL` 的跳表，用的是同一套 **0–95**
的法術編號：

```
0–47   巫師系（職業 2 弓箭手、職業 4 巫師）
48–95  牧師系（其餘職業）
```

分派寫在 root 的 `sub_15644`：

```asm
cmp  byte [bx+0Fh], 2      ; 弓箭手
je   不加
cmp  byte [bx+0Fh], 4      ; 巫師
je   不加
add  [bp-4], 30h           ; 其餘職業 +48
不加:
ax = [bp-4] * 2 + 7D60h    ; SPELLS.DAT 載入位置
```

**旁證**：`2CAST1` 的跳表第 0 項與第 49 項指向同一支 handler
（`sub_1CBEC`）。第 0 項是巫師系第 1 條、第 49 項是牧師系第 2 條 ——
兩者在手冊裡都是「喚醒術」。

`data/spells.json`（抄自手冊）的順序相反，所以 `cmd/mm2data` 產生
`spellcosts.json` 時就把兩半對調成手冊的順序。

## 2. 施法代價

見 [`02-data-files.md`](02-data-files.md) §9。摘要：

```
A 低 nibble   寶石消耗
B 位元 0–3    固定法力消耗
B 位元 4–6    每施法者等級的法力消耗
```

法力 = `固定 + 每等級 × 施法者等級`。

## 3. 會不會：角色記錄 +81

六個位元組 48 個位元，一位一條，低位在前。`Character.Knows(n)` 與
`Learn(n)` 走這個遮罩。

## 4. 效果：兩張跳表，還沒逐條解

`2CAST1.OVL` 的跳表在映像偏移 `0xD1CE`，**97 個 word**，指向六位元組的
trampoline；其中 43 個是實作，其餘指向同一個預設出口（`0x1D28E`）——
那些是由 `2CAST2` 處理的。`2CAST2` 應該有一張對稱的表。

已知的共用零件：

| 位址 | 作用 |
|---|---|
| `sub_1D046` | 顯示提示字串（`ds:315E`）並等 Enter。幾乎每支 handler 開頭都呼叫 |
| `sub_1CF5C` | 施法前的畫面準備 |

### 已解出的七條：牧師系的治療與解狀況

| 引擎編號 | 法術 | handler | 效果 |
|---|---|---|---|
| 3 | 急救術 | `sub_1CC5C` → `sub_1CE46(8)` | 狀況 `&= 2Fh`，生命 +8 |
| 7 | 治傷術 | `sub_1CCA8` → `sub_1CE46(0Fh)` | 狀況 `&= 2Fh`，生命 +15 |
| 16 | 解毒術 | `sub_1CCD6` | 狀況 `&= 77h` |
| 22 | 治病術 | `sub_1CD16` | 狀況 `&= 7Bh` |
| 30 | 恢復術 | `sub_1CD56` | 狀況 `= 0` |
| 33 | 解除石化 | `sub_1CD96` | 狀況**整個等於** `82h` 才作用，清成 0 |
| 39 | 復活術 | `sub_1CDCA` | 狀況**整個等於** `81h` 才作用 |

前五條都先檢查 `狀況 >= 80h`，是的話沒有效果。

**這七條反過來把狀況位元組（記錄 `+38`）的語意定出來**：每一支清掉哪幾位，
那幾位就是它治的東西。

| 位元 | 語意 | 誰清掉 |
|---|---|---|
| 2 | 疾病 | 治病術 |
| 3 | 中毒 | 解毒術 |
| 4 | 急救術治的那一項 | 急救術、治傷術 |
| 6 | 無意識 | 急救術、治傷術（`sub_1AFBC` 在生命歸零時設）|
| 7 | 嚴重（死亡／石化的高位）| — |

而 `82h` = 石化、`81h` = 死亡 —— 那兩條用 `cmp` 比整個位元組，不是測位元。

**代價的交叉驗證**：這七條的 `SPELLS.DAT` 值與手冊逐條相符 ——
1 SP、2 SP、3 SP、4 SP、5 SP+5 寶石、6 SP+6 寶石、7 SP+7 寶石。
七條全中，等於把上一節的欄位切法又驗了一次。

其餘八十幾條的效果**還沒解**。`internal/game/cast.go` 對它們照扣代價、
不假裝有效果（`CastResult.Effect` 是空字串）。

## 5. 誰會施法

牧師、巫師、遊俠、弓箭手。名冊四十筆裡只有牧師與巫師的法力欄位非零，
與手冊「遊俠與弓箭手要較高的經驗等級才有法力」一致。
