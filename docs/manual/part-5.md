## 2. 地圖記錄頁的版面

p.39–65 每一頁一張圖，版面完全固定：

- 頁眉：奇數頁左上「‧魔法門（地圖）‧」，偶數頁右上「‧軟體世界‧」。
- 圖框：16×16 方格，**X 軸 0–15 由左至右標在下緣，Y 軸 0–15 由下至上標在左緣**，
  左下角畫有 `y↑ / x→` 的座標軸符號 → **原點在左下**。
- 頁腳填寫欄（原樣抄錄）：

  ```
  區域：          表面座標：X ＝        Y ＝
  ```

- 頁碼置中，格式如「—39—」。

「表面座標」是玩家自行填寫的欄位，手冊在這一批頁面內沒有進一步說明它的定義。
（字樣已放大確認：是「區域」與「表面座標」，非「區城」。）

## 4. 地圖符號

至少可辨識三類記號（放大 5–9 倍後確認）：

| 記號 | 外觀 | 說明 |
|---|---|---|
| 粗實線 | 明顯比格線粗的黑線 | 牆體 |
| 虛線（點列） | 粗細與粗實線相當，但由圓點組成 | 與粗實線不同的邊界，含義未知。例：p.57 於 X≈5–9、Y≈0–2 圍出一個虛線矩形；p.37（不在本批）亦有小虛線方框 |
| 門記號 | 跨坐在牆線上的小圓角方框「⌸」 | 牆上的開口／門 |
| ▲ | 實心小三角，位於格子中央 | 含義未知。成片出現，常見於外圍走道或整排小格 |
| ● | 實心小方點，位於格子中央 | 含義未知。多出現在大房間或開闊區域 |

**未解**：▲ 與 ● 的意義。本批頁面無圖例，不得從外觀臆測（例如逕自寫成「水域／陷阱」）。

**已排除的誤判**：圖上散布的小十字／星狀斑點（放大後像「✕」或「米」）**不是**地圖符號。
證據是它們在 p.43–46 的**完全空白格線頁上同樣出現且位置隨機**，空白頁不承載任何地圖資料。
判定為原書影印與掃描的雜點，經 JPEG 與放大插值後被放大成十字形。（推論等級：強推論）

**解析度限制（影響所有地圖頁）**：每張掃描為 1280 × 約 620 px，涵蓋一個跨頁；
單張地圖約 425 px 寬對應 15 格，即**一格約 28 px**，格內符號僅 4–6 px。
放大插值無法回復細節，因此：

- ▲ 與 ● 的形狀可分辨，但更細的差異（例如三角形是否中空、點是圓是方）無法判定。
- 門記號「⌸」的細部樣式（單門／雙門／暗門是否有別）無法判定。
- 4–6 px 的孤立小點一律不視為符號（見 §4）。

要把這些地圖與 `MAP.DAT` 逐格對照，現有掃描的解析度不足以逐格判讀牆體以外的資訊，
需要重掃或改以遊戲資料為準。
