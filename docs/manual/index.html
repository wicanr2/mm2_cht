這份手冊是什麼序言與科隆的歷史建立角色操作、畫面與野外遭遇與戰鬥法術系統地圖冊與圖例

這份手冊是什麼

《魔法門 II》1989 年由軟體世界研究開發中心代理進台灣，包裝上印著 「16BIT／角色扮演／魔法門 II／3 片裝／珍藏版 17」，售價 230 元。 盒裡附的中文說明書分上下冊，另有一本地圖冊，加起來 93 頁。

這幾頁把那本手冊重排成看得下去的章節，並且配上 remake 的實際畫面 —— 手冊裡的畫面圖解是黑白印刷的線稿，對照真的畫面比較容易懂哪個欄位是哪個。
發行 軟體世界研究開發中心（高雄郵政 28～34 號信箱）
文字編輯 林宏亮、黃啟禎
美工編輯 陳金泰
規格 適用 IBM XT/AT，記憶 256K RAM，顯示 MGA／EGA／CGA，鍵盤操作
內容 上冊 47 頁、下冊、地圖冊 38 頁、摺頁彩色世界地圖

包裝背面列的「魔法門第二代特點」是當年的宣傳詞，現在讀起來剛好是一份規格表：

  • 超過 250 種活動怪物畫面及武器裝備
  • 多出野蠻人和忍者兩種職業
  • 可僱用其他冒險者加入隊伍
  • 多出 15 種技能
  • 具有自動繪地圖功能
  • 立體前視圖和活動地圖視窗混合

手冊自己就有的不一致

轉錄的時候照原印抄，沒有順手改字。已知的幾處：

位置 原印 應該是
上冊 p.15 內文 Star Game Start Game
上冊 p.22 表頭 精確度 與 p.17 的「準確度」、p.24 的「準確性」是同一項
上冊 p.11 vs 包裝背面 384K vs 256K RAM 兩處數字不一致
下冊 p.44 RETEN RETURN
地圖冊 p.6 尊人使用 疑為「專人使用」
地圖冊 p.4 Fdrview Farview

這些不是轉錄錯誤，是原書就這樣。列出來是因為照著手冊查英文原名時會查不到。

手冊與遊戲對不上的地方

手冊寫的是設計意圖，程式寫的是實際行為，兩者偶爾有落差。這個站遇到落差時 以原版程式為準，並在該處標明。攻略那半邊的矛盾與勘誤 也收了幾條。

章節

  • 序言與科隆的歷史 —— 上冊第一、二章。這一代的世界觀
  • 建立角色 —— 七項屬性、八種職業、五個種族、陣營與性別
  • 操作、畫面與野外 —— 移動、視窗、休息、配備、繪圖、時空旅行
  • 遭遇與戰鬥 —— 遭遇選項、戰鬥九個指令、快速戰鬥
  • 法術系統 —— 96 個法術的完整資料
  • 地圖冊與圖例 —— 兩套圖例、城鎮設施代號、野外與地下城圖

本站的內容來自 1990 年前後《軟體世界》雜誌的《魔法門 II》連載，以及軟體世界研究開發中心發行的 珍017 中文說明書。兩者都是二手資料，人工轉抄且已知有誤植；與原版程式的行為衝突時以原版為準。 地圖與截圖由 mm2_cht 這個 remake 產生。
