## 二、遊戲機制與數值

### 2.1 角色資料欄位定義（上冊 p.27–30）

| 欄位 | 內容 |
|---|---|
| 生命點數 HP | 戰鬥中所能忍受傷害之點數。值為 0 時喪失意識，之後再受任何傷害即死亡。畫面顯示「目前值／該等級最高值」 |
| 法力點數 SP | 施咒可用之法力點數，通常和咒語之等級相同。畫面顯示「目前值／可達到之最高值」 |
| 防護等級 AC | 戰鬥中是否容易受傷的程度，愈高愈不易受傷。**通常由 0—30 級**，視盔甲、盾牌、速度、咒語而定 |
| 法力等級 SL | 所能施放咒語之最高等級 |
| 年齡 Age | **由 18 歲開始**，隨遊戲進行而增加。年老後基本屬性降低、技巧衰退，**到了 80 歲以後可能在過夜休息時死亡**。可用返老還童之法術延遲或減少 |
| 經驗點數 Exp | 由打敗怪物、完成任務累積。**等級 1 到等級 2 約需 2000 點，以後的等級則逐一加倍** |
| 盜行 Thievery | 偷盜行為（解鎖，破壞機關等）之能力。某些物品及訓練可增加 |
| 第二技能 | **每個人在歷險過程中可以學習二項**第二技能 |
| 黃金 Gold | 購置盔甲武器、食物及其他有用物品時使用 |
| 寶石 Gems | 施展某些較高等級的法術時須用到 |
| 食物 Food | **一單位相當於一天之所需**，也是回復生命點數／法力點數所必需。**開始時每個人物攜帶 10 單位，最多可帶 40 單位** |
| 狀況 Con | 見 §1.3 |
| 配備 Equipped | 目前可使用之武器、盔甲及盾牌等。**每個人最多可以配備六項物品**，且受邏輯限制（一次只能穿一件盔甲、只能使用一項雙手操作之武器等） |
| 背包 Backpack | 目前所攜帶、無法立刻使用（必須經過配備）的物品。**每個人最多可攜帶六項物品** |

### 2.2 傭兵（Hirelings）規則（上冊 p.30–31）

傭兵不是創造出來的人物，是在旅店（Inn）中僱請來的。被僱用後行為與控制均和正常人物相同，例外如下：

1. 遊戲開始時沒有傭兵可選；完成某些使命或行為後，特定旅店中才有可供選擇之傭兵出現。到旅店登記時可檢查是否有供你隊伍選擇之傭兵。
2. **每天結束時必須付傭兵工資**；付不出時他們會離開隊伍，回到前一次儲存遊戲的旅店。
3. 可隨時將傭兵解散（Dismiss），讓他們回到前一次儲存遊戲時之旅店。
4. **檢視傭兵資料時，黃金項顯示的不是他目前擁有的黃金，而是這位傭兵的日薪。**
5. 傭兵在收集及分配黃金時不加入計算。
6. 傭兵可以免費受訓以增加經驗及法力等級，但**每日工資也將上漲**。
7. 傭兵之姓名不能更改，也不能刪除傭兵。

注意：隨意虐待傭兵（如放在最前線、取走物品而不給相當等級物品）會使他們不高興而提高每日工資。

### 2.3 從《魔法門 I》傳送人物（Transfer Characters，上冊 p.31）

- 傳送會把**全部 18 個人物**（不論有無這麼多人物）資料拷貝到預設的六個人物後面，可能蓋掉自己創造的人物資料。**應先傳送人物再創造新人物。**
- 傳送來的人物資料會被修改：

| 項目 | 傳送後的值 |
|---|---|
| 黃金 | 設定為 1000 |
| 食物 | 設定為 40 |
| 寶石 | 最多為 100 |
| 等級 | 低於七級不變，高於七級者減為七級 |

- 若執行好幾次傳送人物，**最前面的 6 個位置均將設定為《魔法門》第二集之預設人物及其基本屬性**。
- 手冊警告：由於程式有雙蟲（原書用字），若用前一代人物進行遊戲，將找不到特別隊員。

### 2.4 隊伍組成（上冊 p.34–35）

- 在城鎮畫面按 `Ctrl` + 人物之代表鍵，把人物加入隊伍或自隊伍中刪除；加入後名字前面打 `V`。
- 一支探險隊伍可由人物及傭兵組成：
  1. **至少有一名人物，最多有六名人物。**
  2. **最多七個傭兵。**
  3. **二者之總數不能超過八名。**
- 手冊舉例：標準隊伍為六名人物 + 二名僱傭。
- 已有八名隊員後要再加入，必須先刪除一名。
- 隊伍組成後按 `Z` 離開旅店，進入三度空間遊戲畫面。
- 要結束遊戲並存檔，必須把隊伍帶到五個城鎮中之任一旅店並登記。

### 2.5 移動與遭遇基本規則（上冊 p.36）

- 前進或後退時整隊往前／往後移動一個方格；左轉或右轉在原方格轉 90 度。
- 隊伍前進時，**未上鎖的門會自動打開**；被鎖著則必須解鎖（Unlock）、撞門（Bash Door）或另找路繞過。
- **大部份上鎖的門均設有機關**，解鎖或撞門時可能啟動機關。
- 碰到牆壁或山脈等障礙時出現訊息：障礙物（Solid）或無法通行（Impassable）。
- 隊員姓名以反白顯示，表示其狀況不佳。
- 螢幕上出現的是整個隊伍向前看到的景象，所以看不到自己的隊員。

### 2.6 地圖與繪圖（上冊 p.37–38、下冊 p.5）

- 螢幕上可看到地圖上 **3 格寬、4 格深**的景物，除非有其他物體阻擋視線。
- 書後附 1 號城鎮的平面地圖，以方格表示，一格 = 隊伍移動一次的距離。附圖已標出旅店、商店（食品、武器）、神廟（治療、救傷）、訓練中心（提升等級）、走道、牆壁、門的位置，但未標實物、怪物位置。
- 繪圖技巧（p.37–38）：
  1. 用書後空白地圖自行繪製，連接相鄰的點以指出牆或其它可見事物，留下的就是空地和通道，並在探險過的區域上作記號。
  2. 看到的均是前視圖；每移動一個方格便記錄一次。
  3. 隊伍轉向時地圖也要轉向；方向感不佳者可先記錄所看到的景物再繼續移動。
  4. 標示鎖住的門、秘密通道、黑暗區域、特殊狀況（尤其在野外）及各種訊息。
  5. 標示一定會出現怪物的區域（如惡龍巢穴），但不要把所有遇到怪物或實物的地點都標出來（大部分是隨機出現）。
  6. 需要正確座標及方向時可用巫術 1—6 的定位法術；鷹之眼、巫師之眼法術可在畫面右上角顯示一個小地圖。
- 手冊「筆者註」：在第一個城市 **X:8　Y:4 向南**的地方可找到一個噴泉，喝下泉水可有暫時的鷹之眼、巫師之眼效果。
- 自動繪圖（下冊 p.5）：**必須有一名隊員具有製圖家（Cartographer）第二技能**才有此功能。使用位置（Location）法術時，目前隊伍所在地區之 **16×16 地圖**及隊伍的位置、方向均會顯示在畫面上。只能看到目前所在地之地圖。
- 鷹之眼／巫師之眼作用時的視窗顯示**隊伍週圍 5×5 範圍內的地圖**（上冊 p.41–42）。

### 2.7 防護效用視窗（Protect，上冊 p.41）

- 顯示目前涵蓋整個隊伍的保護法術。
- 照明（light）法術後的括號是**光源單位，每單位可照亮一格**。
- 魔法防護顯示對於**地、水、風、火、毒、恐懼**的防護百分比。
- 其他法術則在有作用時顯示。

### 2.8 其他視窗（上冊 p.42）

- 橫跨畫面中間是狀態顯示欄，內有年、月、日、隊伍面對之方向及其他訊息。
- 上面所列的指令可切換防護效用視窗與指令視窗。
- 畫面下半部是每名隊員的簡要資料。

### 2.9 休息與搜尋（上冊 p.39）

- 休息（Rest）：在目前地點紮營過夜，可恢復所有隊員之生命點數、法力點數，但**死亡、中毒、痲痺、石化、根除等狀況除外**。
- **每位隊員會消耗一份食物**，長效性法術的效用也會消失。
- 休息時常會有敵人來襲；隊員若還在呼呼大睡，麻煩就大了。**某些極危險地帶根本不允許隊伍休息。**
- 隊伍休息時時間仍不斷流逝，有些事情和時間有關。
- 搜尋（Search）：在目前地點找尋隱藏的物品或寶箱。戰鬥後不要忘了用 `S` 找尋戰利品。

### 2.10 配備規則（上冊 p.41）

- **最多可裝上 6 種物品。**
- 武器、盔甲、盾牌必須配戴後才可使用。
- 護甲只能穿一件。
- **只能同時手持一把近戰及遠程武器**；手持雙手用武器就不能再用盾牌。
- 藥品、工具可在背包內使用。
- 按字母鍵 `A`–`F` 選擇物品；卸下（Remove）時輸入 `1`–`6`。

### 2.11 遭遇與戰鬥（上冊 p.42–47）

**遭遇階段（p.43）**

- 遭遇其他生物時，畫面上的防護效能欄（protect）或指令欄（options）會被怪物名稱數量所取代；畫面出現怪物長相，中央訊息欄出現一組指令選擇項。
- 若隊伍被怪物偷襲，將毫無選擇地進入戰鬥；若先察覺到怪物，有前進（Advance）或離開（Leave）兩種選擇。

**雙方對陣選項（p.43–44）**

| 指令 | 規則 |
|---|---|
| Attack 攻擊 | 馬上進入戰鬥狀態 |
| Bribe 賄賂 | 怪物同意時出現 `bribe with what:food, gold, gems`，選擇其中一種、輸入數量後按 `RETEN`（原書誤植，應為 RETURN）。滿意即離去，不滿意則馬上開打 |
| Hide 躲藏 | 在原地找個地方躲起來，**失敗機會很大**。成功則隊伍留在原地 |
| Run 溜跑 | 成功則隊伍移動到 **16×16 範圍內的安全地點**；被敵人追上則戰鬥立即開始 |

**戰鬥規則（p.44–45）**

- 決定誰先出手的因數最主要是**速度**，速度快者先攻擊。**每回合每人只能出手一次。**所有人動作完畢後下一回合開始。
- 怪物的名稱變反白時，表示牠正在動作。
- 輪到隊員動作時，指令欄顯示目前動作隊員的名字及可能的指令。
- 怪物或隊員名稱前面有 `V` 記號，表示正處於肉搏戰中。
- **非弓箭手的隊員無法使用投射類武器（弓，矛之類）。**
- 底下人物狀態欄內名稱的次序就是戰鬥時的位置；**次序愈後就離敵人愈遠**。
- 人物名字反白表示他已受傷、中毒或更遭。
- 取得優先權時只有 **9 種指令**可供選擇。每次行動完畢後結果會立即顯示，停留時間可用延遲（`D` 鍵）指令更改。

**戰鬥指令細節（p.45–46）**

| 指令 | 規則 |
|---|---|
| Attack 攻擊 | 用現有武器攻擊敵方隊伍最前方的敵人。此人死亡則由後面敵人遞補 |
| Fight 戰鬥 | 用現有武器攻擊敵方在肉搏戰場內的敵人，可按字母鍵選擇敵人 |
| Shoot 射擊 | 使隊員發射投射性武器。**只出現在配備投射武器且未在肉搏戰場中的隊員選擇項內**；但弓箭手無論是否在肉搏戰場中都可使用。可攻擊敵方隊伍任一名敵人 |
| Cast 施法 | 依序輸入法術等級及代碼 |
| Use 使用物品 | 輸入物品的代號（`A`–`F` 或 `1`–`6`） |
| Block 抵擋 | 在該回合增加防禦效用 |
| Run 溜跑 | 企圖逃離戰場。成功後三種情形：①隊伍勝利，此人歸隊；②隊伍全滅，此人回來收拾殘局；③隊伍全溜，戰鬥終止並立即重整隊伍 |
| Exchange 對調 | 和其他隊員交換位置（把重傷的人移到隊伍後面加以保護）。輸入互換兩名隊員的代號即可 |
| View 檢視 | 檢視此名隊員的狀況 |

**快速戰鬥（p.46–47，適合較高等級隊伍）**

同時按住 `Ctrl` + `A`，電腦自動安排隊員的動作：

1. 在肉搏戰狀態攻擊在 A 位置之怪物。
2. 若擁有投射武器且不在肉搏戰狀態，則射擊在 A 之怪物。
3. 其他狀況則採取抵擋行動。

**戰鬥結束（p.47）**

- 戰鬥持續到其中一方均撤離或全部死亡後結束。
- 隊伍戰勝則出現訊息告知每個存活下來的隊員可得到多少經驗點數。
- **有隊員石化、死亡或根除則得不到經驗點數。**
- 離開結束戰鬥之位置前，務必搜尋（Search）是否有怪物留下之寶物。

### 2.12 結束遊戲及儲存進度（上冊 p.47）

- 回到任一城鎮中之旅店，在櫃台詢問是否要登記（Sign in）時回答 `Y`（Yes）。
- **隊伍全部死亡後，將回到上一次儲存進度之旅店**；這段時間內碰到之重要任務或找到之線索均須重新做一次。
- 可以同時有幾組隊伍分別有不同之遊戲進度。

### 2.13 世界與城鎮設施（下冊 p.1–2）

城鎮中的四類設施：

| 原文 | 中文 | 功能 |
|---|---|---|
| （未附英文） | 商店 | 供給食物、武器、盔甲及其他各種裝備 |
| Temples | 神廟 | 治療生病或受傷之隊員 |
| Training grounds | 訓練基地 | 隊員累積足夠經驗點數後可在此受訓以提升等級 |
| Inns | 旅店 | 每個階段遊戲結束後休息的地方，也是儲存目前遊戲資訊的地方 |

其他世界規則：

- 整個科隆世界有許多城鎮、神秘的洞穴、危險的地下城、莊嚴的城堡以及危險的野外地區。
- 地下洞穴及地下城通常有好幾層，**愈低層危機及收獲愈大**。
- 城堡提供很多任務，達成後獲得黃金及經驗點數作為報償。
- **野外地區可分為五大部份：四個自然地區（水、風、火及土）和中央世界。**
- 怪物隨時可能出現在原來沒有危險的地方；魔術傳送門（Magical Portals）也會隨時出現或消失。

### 2.14 人物基本規則（下冊 p.2–4）

- 人物由職業（CLASS）、種族（RACE）、陣營（ALIGNMENT）及性別（SEX）來定義，**其中又以職業為最重要之特性**。
- **任何創造的人物，不論職業、種族、陣營和性別為何，年齡均為 18 歲，經驗等級則是 1。**
- 同屬一個職業的人物會有某些相同的能力和限制，但不會完全相同。
- 不同職業的人物可穿著不同的護甲，使用不同的武器。其它配備物品（羅盤、繩索、燈具等）可在商店購得或在旅途中找到。
- **每個人都有一個背包（BACKPACK），最多可攜帶 6 項物品**；裝滿後除非丟棄或轉讓，才能容納新物品。
- 除了背包外，**每個人身上還可以配備六項物品準備使用**。盔甲和大部分武器都必須經過配備（Equipped）才能使用；只放在背包中直接戰鬥則無法發揮作用。
- 怪物：**《魔法門 II》中有超過 250 種不同的怪物。**通常遇到的怪物會和全體隊員的經驗等級相當。怪物通常均守護著寶物，所以較高等級之人物有較多機會獲得財富。
- 任務（Quests）：有接受或拒絕的權利，接受就必須完成才能獲得經驗點數。**可以同時有幾個任務在身，但有時需要到神殿去解除現有任務，以讓你能完成其他任務。**

### 2.15 法術系統（下冊 p.4、p.6）

- **全部有 96 個法術，48 種神術及 48 種魔法。每一類又各自分為 9 個等級。**
- **一個人不可同時學習兩種法術**（下冊 p.4）。
- 施法者可以施放其法力等級及較低等級之法術；施用時遊戲會問等級及編號。
- 法力等級與人物經驗等級的對應：

| 法力等級 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 經驗等級 | 1 | 3 | 5 | 7 | 9 | 11 | 13 | 15 | 17 |

- 昇級時可能會漏學某些法術，必須在牧師神殿（Temple of Cleric）或法師協會（Mage Guild of Sorcerers）用錢購得。
- 每一個能施用法術的隊員均有一本法術冊；同一列上能施用之法術以 `V` 號表示。
- 較高等級的法術除消耗法力點數外**還要寶石來提供能量**。
- 注意（下冊 p.7）：**大部分的怪物對某些法術有抗力**，無法保證施用後一定有效。戰鬥中施用的法術也可能在戰鬥結束前被怪物破解掉。每一個戰鬥回合中，怪物均將嘗試破解加諸在其自身上之法術。**有些怪物甚至能施用反法術（Dispel）破解正作用在怪物或隊伍上之法術全部失效。**

### 2.16 時空旅行（下冊 p.5）

- 開始時已經在科隆紀元第十世紀（900 年），這是遊戲之實際時間，**只能暫時地回到過去的時空探訪**。
- **每一個世紀都有其獨特之處**，因此地點、人物和物品均不一定相同。
- **每一次時空旅行之時間均受程式以亂數控制。**
- 在休息時，可以傳送回到十世紀中你離開的那一刻。
