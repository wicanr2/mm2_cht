# 《軟體世界》MM2 私有研究索引

這個目錄是《軟體世界》連載的**私有研究區**。可保存逐字轉錄、頁碼對照、
辨讀不確定處與供 remake 交叉驗證的筆記；不屬於公開釋出物，亦不可直接複製到
公開 GitHub repo。

公開可用的原創文章在 [`../../columns/soft-world/`](../../columns/soft-world/)。
兩者只能用「期別／頁碼／證據等級」互相對照，不能把這裡的正文、圖表或地圖
搬過去。

## 連載取得狀態

| 期別 | MM2 頁面 | 研究狀態 | 主要缺口 |
|---|---:|---|---|
| 005 | 50–55 | 已人工轉錄（私有草稿） | 五張地圖格位與少數小字仍待驗 |
| 006 | 40–45 | 已人工轉錄 | 15 張地圖尚未轉成格位資料；部分右緣裁切 |
| 007 | 45–48 | 已人工轉錄 | 8 張地圖尚未轉成格位資料；少量小字不清 |
| 008 | 28–30 | 已人工轉錄 | 8 張地圖尚未轉成格位資料；頁尾淡字 |
| 009 | 36–39 | 已人工轉錄 | 地圖格線與小字尚未可靠轉錄 |
| 010 | 40–41、53–59 | 已人工轉錄 | Last Dungeon 格位、反白十六進位畫面與少量表格欄位 |

第 006–010 期的現有稿是「全刊逐頁盤點＋MM2 相關頁人工轉錄」，不是整本
雜誌的全文 OCR。任何新增轉錄都要保留來源位址、掃描頁與印刷頁的對照，無法
辨讀處標記為不確定，不以猜測補字。

私有掃描的 OCR 草稿以 `mm2-ocr` image 內的 `soft-world-ocr` 產生；輸入必須
唯讀掛載、輸出必須是工作樹外的私有目錄，工具會拒絕寫入 `/src`。OCR 只是一份
待人工覆核的草稿，不能直接視為逐字轉錄或遊戲規則。

## 研究與公開的交界

- 研究稿可記錄原文與掃描品質，但只在私有工作 repo 使用。
- 公開專欄只寫自己的分析、摘要、驗證結果與勘誤；不引用可替代原文的長段文字。
- 雜誌敘述只是二手佐證。與 DOS oracle、原版資料或已證實的反組譯衝突時，
  保留衝突與來源，不把雜誌敘述升格為遊戲規則。

公開前以 `tools/check_release.sh --public` 驗證；該檢查會拒絕這個研究目錄與
`data/hints.json`。
