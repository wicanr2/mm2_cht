# Blurglecruncheon 的 MM2 攻略站調查

作者：Andrew Schultz 
最後更新：2001-03-01
取用日期：2026-08-18
網址前綴：`http://www.geocities.ws/blurglecruncheon/mm2/`

Geocities 上一個 1990 年代的 MM2 攻略與地圖資源站。主要內容包括手繪地圖、逐部門玩法攻略、傭兵清單與已知 bug。

## 1. 頁面概況

### main.htm — 索引頁

**內容型態**：文本索引 + 表格框架
**規模**：不到一頁

主頁介紹作者在高中時期喜愛 MM2，認為相比 MM1 更規律、更容易由一個人逆向。

列出的主要內容項：
- 地圖（已色化中）
- 攻略（FAQ 與走完整流程的 walkthrough）
- 世界地圖拼圖（「strung together a patchwork world map」）
- 傭兵（hireling）頁面
- 原版 bug 清單

提及「幾乎完成了所有地圖，並找到所有 MM2 的物品與怪物」。該站是 WebRing 會員（一個 1990 年代的網站連結網絡）。

### maps.htm — 地圖索引

**內容型態**：表格索引 + 文本描述
**規模**：約 30 張圖與對應的 HTML 連結

按類別組織的地圖：
- **戶外地圖**：Cron 的 5×5 網格世界（A–E 行，1–5 列），加上完整世界地圖
- **五個城鎮**：Middlegate、Atlantium、Tundara、Vulcania、Sandsobar，各含城鎮圖與地下城圖
- **洞窟**：13 個，按字母順序列出（Corak's Cave、Dawn's Mist Bog、Dragon's Dominion 等）
- **城堡**：Woodhaven、Hillstone、Pinehurst、Luxus Palace，各含表面與兩層地下城
- **元素平面**：Fire、Water、Earth、Air 各一張

頁面明確標示「Woodhaven Level 2 還在開發中」（尚未完成），大多數 HTML 連結當時標示為有效。

### mm2walk.txt — 完整玩法攻略

**內容型態**：純文本、多段落、詳細步驟
**規模**：約 16,600 字（30 KB）

這是一份逐步走完遊戲的完整攻略，包括：

**新手指南**
- 以骷髏為練習怪物的升級方法
- 如何透過重複領 Nordon 的任務刷經驗

**五個城鎮的任務表**
- Middlegate：取高杯、自動地圖技能、傳送門
- Atlantium：迴避戰鬥、訓練設施、池塘增益、雕像線索、逃獄夥伴
- Tundara：傭兵位置、翡翠戒指
- Vulcania：（簡短提及）
- Sandsobar：地下城探索

**全城鎮共同任務清單**
- 五座神廟捐獻獲得 Fe Farthing
- 在 Middlegate 噴泉擲出城堡鑰匙
- 四座城堡的城市鑰匙收集
- 各城堡解救主教（三個「值得度」條件之一）
- 三個競技場各式票券戰鬥（12 張總計）
- 職業特定考驗（詳見下）

**八個職業特定考驗**
- Knights（Jouster's Way）：簡單
- Archers（Baron Wilfrey）：中等難度
- Clerics（Corak's Cave）：涉及 Corak's Soul + Admit 8 通行證
- Sorcerers（Isle of Good/Evil）：知道正確的門就很簡單，需要釋放 Ybmug 與 Yekop（Gumby 與 Pokey 反寫）
- Paladins（Frost Dragon's Cave）：找到冰龍
- Barbarians（Brutal Bruno）：類似騎士路線
- Ninjas（Dawn）：難度高，Ninja 不能施法但需大量治療
- Barbarians（Murray）：（重複條目？）

**主線流程**
- 找 Sherman 與 Nakazawa，帶 Sherman 到 Pinehurst 開啟時間旅行
- 進入 800 年代的城堡 Xabran，收集四張磁片
- 打敗四個元素平面的敵人獲得塔隆（Talons）
- 從 Dawn's Mist Bog 獲得寶石球（Orb），僱兵帶著然後解散（防止離不開該區域）
- 回 800 年代給 Kalohn 物品，他打死巨龍（Mega Dragon）
- 進入 Cave Geometricus
- 打敗 Sheltem
- 解密碼謎題（密文是替代加密，明文是泰拉憲法序言，關鍵詞是 "Preamble"，取小寫字母解碼）

**按部門的側任務**
詳細列舉五行五列世界地圖的每一格（A1–E4）的特殊 NPC、物品或怪物（例如 Meenu the pegasus、The Gourmet、The Cuisinart 等怪物首領）。

**作弊技巧**
- 磁片交換法複製翡翠戒指
- 磁片交換法複製金錢
- 經驗值上限：16,777,216 金（不同於 MM1 的無限累積）

### patch.htm — 世界地圖拼圖

**內容型態**：視覺地圖 + 簡短文本
**規模**：一張可交互拼圖

宣告可右鍵拉出各個部門（sector）的個別檢視，並提供地圖鑰匙。由於是主要視覺內容，純文字版本收穫有限。

## 2. Bug 清單詳解

**現象**那一行是站上寫的（推論等級：`已證實`，站上原文如此，但**站上的說法本身
沒有經過我們查證**）。**Remake 考量**那一行是我們自己的提問，不是站上的內容，
也還沒有一條回去對過反組譯（推論等級：`未知`）—— 逐條裁決要靠 DOSBox 實測，
列在 [`docs/todo.md`](../todo.md)。

原版的 bug 對 remake 是**要知情地決定**的東西：照抄還是修掉都行，
不知道它存在而「順手修掉」不行。

**Bug 1：Dead Heads 角色經驗與血量溢位**
- 現象：Dead Heads 攻擊低等級角色時，角色會失去經驗與生命值。若血量降到零以下，會循環回復到接近 65536（2^16）。
- 觸發條件：Dead Heads 在低等級角色戰鬥中攻擊造成大傷害
- Remake 考量：**可能需要考慮是否照抄無符號整數溢位行為**。原版是 16-bit 無符號，可能有意或無意；Remake 使用有符號或更大整數型別時此行為不會自動發生。

**Bug 2：Druid 沈默咒語的法術仍可施放**
- 現象：Druid 施放 Silence 後，隊伍在戰鬥外仍可施放法術。
- 觸發條件：被 Druid 沈默後離開戰鬥
- Remake 考量：**應確認沈默狀態的作用域** — 戰鬥內只禁法術還是全域禁止，以及離圖/改圖是否清除。

**Bug 3：Etherealize 傳送邊界錯誤**
- 現象：從 (0,0) 向西傳送會抵達 (15,15)；從 (x,0) 向西傳送會抵達 (x,15)。
- 觸發條件：在指定座標使用 Etherealize（乙太化）法術向西
- **這一條我們對過了，對不上**：穿透術是 `sub_1C722`，我們的實作照它寫成
  `X=(X+dx)&0x0F`、`Y=(Y+dy)&0x0F`（`internal/game/cast.go`）。向西時 `dy` 是 0，
  所以從 (0,0) 往西只會到 **(15,0)**，不是站上說的 (15,15)。
  兩種可能都沒排除：站上的座標寫法與我們相反（那 (x,0)→(x,15) 那句就說得通），
  或者原版在移動之後還有一段我們沒看到的調整。**用 DOSBox 走一次就能裁決**，
  已排進 [`docs/todo.md`](../todo.md)（推論等級：`未知`）。

**Bug 4：Enchant Item 法術消耗計算錯誤**
- 現象：Enchant Item 有時會減少不正確的法力點數（差 512 倍），導致提升等級越高消耗法力越少（例如 +15 比 +5 便宜）。
- 觸發條件：施放 Enchant Item 時
- Remake 考量：512 = 2^9，聞起來像位移或 word／byte 取錯，但**我們沒有回去看
  附魔那一支的反組譯**，成因未知。要查的是：我們的實作扣的 SP 與原版逐級是否相同。

**Bug 5：Sarakin 重複出現**
- 現象：擊敗 Sarakin 後仍會再次遇見他。
- 觸發條件：重新進入 Sarakin's Mine
- Remake 考量：**敵人旗標未持久化**。可能只在戰鬥時設置旗標，存檔沒有保存，或離圖/關機後重置。

**Bug 6：水域平面休息後邊界錯誤**
- 現象：在水平面休息後，嘗試越過邊界（例如東邊從 15,3）會看到「can't swim」訊息。
- 觸發條件：在水平面休息（rest），然後嘗試移動超出邊界
- Remake 考量：**狀態未正確同步**。休息可能重設了某個水域相關的旗標或座標。

**Bug 7：Nature's Gate 從城堡 Xabran 傳送目標錯誤**
- 現象：從城堡 Xabran 施放 Nature's Gate 會回到 900 年代，但休息或進城鎮會「調整」位置。
- 觸發條件：在 Castle Xabran（800 年代）施放 Nature's Gate
- Remake 考量：**時間判準混淆**。可能是讀到了錯的時代標籤或邊界檢查順序。

**Bug 8：屬性氣球膨脹 (Stat Balloon Exploit)**
- 現象：裝備可能增加屬性的物品，令該屬性變為零，然後脫掉再穿上，該屬性會變成正數並疊加。
- 觸發條件：裝備增加某屬性的物品 → 交易該屬性至零 → 脫掉物品 → 重新裝備
- Remake 考量：要查的是屬性交易與裝備加值的先後順序 —— 我們的實作是先算基礎值
  再疊裝備，還是像站上描述的那樣讓兩者互相污染。

**Bug 9：喝泉水提升法術等級邊界**
- 現象：在 C1 (1,11) 的噴泉喝水可將法術等級提升到 9。副作用是電腦會讓騎士/野蠻人/忍者/盜賊獲得法術選項，但他們沒有可施放的法術。
- 觸發條件：喝 C1 (1,11) 的特殊噴泉
- Remake 考量：要查的是「法力等級」與「這個職業有沒有法術書」在原版是不是兩件
  獨立的事。站上沒說按下去會怎樣，**我們也不要替它假設**。

**Bug 10（非 Bug）：Lord Haart 任務無法完成**
- 現象：雖然可以擊敗 Spaz Twit，但沒有其他怪物或物品可以完成 Lord Haart 的任務。
- 觸發條件：嘗試完成 Lord Haart 的請求
- Remake 考量：**這是設計不完全，不是程式錯誤** —— 任務觸發物件遺漏或條件檢查不存在。

**Bug 11（非 Bug）：傳送術在過去城鎮變空**
- 現象：在過去時代（800 年代？）對特定城鎮施放 Town Travel (8-4) 會導致城鎮完全空蕩蕩，無法離開。
- 觸發條件：時間旅行到過去，對城鎮施放 Town Travel
- Remake 考量：**設計與時間邏輯的交互作用** —— 過去城鎮可能沒有資料，傳送術不檢查時代。

**補充觀察：A3 的隱藏聲音**
- 在 A3 的兩個噴泉後方，右邊那個可以聽到「got me」的聲音，離開後仍可聽到。
- 推測：音效觸發器未正確清除，或特定區域有持久的聲音標記。
