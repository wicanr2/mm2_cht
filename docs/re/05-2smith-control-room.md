# 結局控制室：`2SMITH` 的第二個入口

輸入檔：`MM2.EXE` ＋ `2PLAY.OVL` ＋ `2SMITH.OVL` ＋ `STR.DAT` ＋ `MONSTERS.DAT`
（SHA-256 見 [`inventory.md`](../inventory.md)）。IDA 位址取自
`workplace/ida/out/2SMITH.asm`、`2PLAY.asm` 與 `workplace/ida/MM2.EXE.i64`。

`2SMITH` 有兩個入口，事件腳本的 `0x0e` 各自對到一個：

| 代碼 | 進入點 | 內容 |
|---|---|---|
| `0e 06` | `_2smith_e00`（`+CCBA`）| 鐵匠，見 [`../formats/02-data-files.md`](../formats/02-data-files.md) §商店 |
| `0e fd` | `_2smith_e01`（`+CEC8`）| **結局控制室** |

鐵匠與控制室共用一個 overlay，只是因為兩者都要買賣選單那套繪製常式；
玩法上沒有關係。

---

## 1. 進入路徑

`2PLAY` 的 `0x0e` 分派器 `sub_19716` 在 `0xFD` 這一格呼叫 thunk `0x17396`
（→ 2SMITH `+CEC8`），**一次**，回來之後再依 `ds:0395` 分支：

	loc_197F0:
	    call  loc_17396          ; _2smith_e01
	    ds:0395 == 2 → ds:0392 = ds:03D4；ds:043A = 1；call loc_173DE  ; 1RETINN +C1EA
	    ds:0395 == 3 → call loc_171E6                                  ; root 0x13FD8
	    否則         → ds:0395 = 1

`ds:0395` 的三個值全部由 `2SMITH` 自己寫：

| 值 | 誰寫 | 意思 |
|---|---|---|
| 1 | `_2smith_e01:loc_1CF6C` | 沒進到控制室（`ds:0509 == 0`）|
| 2 | `sub_1D2A4:loc_1D7D0` | **密碼解對，遊戲通關** |
| 3 | `sub_1D2A4+384` | **時間到，沒解出來** |

## 2. `_2smith_e01`：守門的那場仗

	ds:50FF = 0xFD                       ; 場景碼
	loc_16DF6(0)                         ; 版面切換
	memset(ds:9680, 0, 11)               ; 清空 11 格怪物槽
	for si in 0..3:                      ; 印 ds:58B8 四行
	    loc_16F2E(1, si + 0x13); loc_16F52(*(ds:58B8 + 2*si))
	loc_17042()
	ds:9680..9684 = FF E1 C2 C1 E0       ; 怪物清單
	ds:0415 = 0x83                       ; 遭遇型別
	memset(ds:9685, 0, 6)
	sub_1720A()                          ; 打這一仗
	if (ds:0509 != 0) { loc_1704E(-1,-1,-1); sub_1D2A4(); }
	else                 ds:0395 = 1

### 怪物槽 `ds:9680`

五個位元組就是 `MONSTERS.DAT` 的編號：

| 值 | 編號 | 名稱 |
|---|---|---|
| `FF` | 255 | Sheltem |
| `E1` | 225 | Water Elementl |
| `C2` | 194 | Air Elemental |
| `C1` | 193 | Fire Elemental |
| `E0` | 224 | Earth Elementl |

一隻首腦加四隻元素生物，與 `str.280`「Sheltem and his Elementals guard the
entry to the control room.」逐字對得上。槽位共 11 格（前後兩次 memset 合起來是
`ds:9680`–`ds:968A`）。

`ds:0415 = 0x83` ＝ `0x80 | 3`。`2COMBAT` 對這個旗標做 `cmp byte_10415, 80h`
之後 `sub byte_10415, 80h`，所以高位是特殊遭遇的標記、低位是型別；
競技賽（`_2brain_e00`）在同一個位置寫 `0x80`。

### `sub_1720A` 是「開打」不是「準備」

root `0x13EB2`。它備份 `ds:0416` 八個字（隊伍位置 → 名冊索引）與 `ds:0426`
（隊伍人數）到 `ds:5976`／`ds:5974`，呼叫 thunk `0x17072`（→ **2COMBAT `+A2A6`**），
回來後還原那兩份、逐一把每個角色的 `+0x27` 寫回 `+0x73`、`+0x15` 寫回 `+0x70`，
再呼叫 `sub_13E82` 與 thunk `0x172A6`（2PLAY `+B75E`）重畫。

競技賽走的是同一支，所以這個形狀是「用 `ds:9680` 的清單打一場特殊戰鬥」的
共用寫法，不是控制室專用。

### `ds:0509` 是進控制室的閘門

DGROUP 初值段裡 `ds:0509 = 0x75`（非零）。`_2brain_e00` 用完會把它清成 0；
`2PLAY` 有三處讀它。**把它設成非零的寫入端沒有找到** ——
`10509` 這個字面值在 14 份 `.asm` 裡只出現讀取端與 `2BRAIN` 的清零，
而 `mov word ptr ds:508h, ax` 這類寫法或指標間接寫入都不會留下這個字面值。
等級：**未知**。

## 3. `sub_1D2A4`：控制室

### 3.1 四十七條字串一次讀進來

開場 `sub_17732(3)` ＋ 四十七次 `loc_1773E`，照寫死的順序填六張指標表。
兩支常式的機制與酒館那七張表相同（見 [`04-2brain-tavern.md`](04-2brain-tavern.md)）：
`sub_17732(N)`（root `0x1670A`）解開 `str.dat`，從 `ds:52F4[N]` 起搬 2400 bytes
到 `ds:A06E`，逐位元組 `+0x1C`、`0x1D` 換成 `0`；`loc_1773E`（root `0x167BC`）
回傳 `ds:A06E + ds:52F2` 並把游標推到下一個 `0` 之後。

`ds:52F4` 的前五格是 `0x0000`／`0x063C`／`0x0F5C`／`0x1286`／`0x1844`，
換算成行號就是 `str.0`／`str.88`／`str.244`／**`str.280`**／`str.327`。
所以控制室拿的是 `str.280`–`str.326`：

| 指標表 | 條數 | `STR.DAT` | 用途 |
|---|---|---|---|
| `ds:58B8` | 4 | 280–283 | 守門的旁白（由 `_2smith_e01` 印）|
| `ds:58C0` | 4 | 284–287 | 中止碼的提問畫面 |
| `ds:5892` | 14 | 288–301 | Sheltem 的預錄訊息 |
| `ds:5846` | 4 | 302–305 | **要被加密的那四行**（泰拉憲法序言）|
| `ds:5868` | 11 | 306–316 | 通關賀詞 |
| `ds:587E` | 10 | 317–326 | 戰績、分數與 New World Computing 的通訊地址 |

### 3.2 兩道前置關卡

	讀 endgame.16（loc_16EAA(ds:0500)，ds:0500 → "endgame.16"）並畫出來
	印 ds:45BC「A vaccuum tube sucks the party into」
	印 ds:45E0「        the control room...」
	印 ds:58C0 四行（第 17–20 列）
	loc_16EE6(&buf, 10)                  ; 讀十個字，不足補空白
	數隊伍裡記錄 +129 bit 5 為 1 的人數 → di
	strcmp(buf, ds:45FC) != 0  → 失敗
	di == 0                    → 失敗

`ds:45FC` 的內容是 `"WAFE      "`（四個字母加六個空白，共十格）。
兩道關卡任一沒過都跳到失敗分支，畫面只有一行 `Incorrect!`（`ds:469C`）——
**分不出來是密碼錯還是沒有那個旗標**。

`+129` bit 5 的來源是 `EVENTSI` 段 69 腳本 2（拿到 Square Lake 的指令），
見 [`03-character-flags.md`](03-character-flags.md)。

### 3.3 密碼題

過關之後印四行台詞（`ds:4607`／`ds:461B`／`ds:463B`／`ds:4660`，中間各停 300），
重畫 `endgame.16`，印 Sheltem 的十四行預錄訊息，然後：

	sub_1D19C()                          ; 產生隨機替代字母表
	印 ds:5846 四行，每個字元先過 sub_1D1FC
	印 ds:4681「Answer= Preamble     Code=」
	for i in 0..7: ds:58AE[i] = sub_1D1FC(*(ds:45BA)[i])
	ds:0436:0438 = 0x000DBBA0            ; 900,000

**`ds:45BA` 是個指標，值 `0x45B0`，指向字串 `"Preamble"`（8 個字元）。**

#### 替代字母表（`sub_1D19C`，`0x1D19C`）

	used[0..25] = 0
	for i in 0..25:
	    do   v = loc_16F76(1, 26) - 1     ; rand(1,26) - 1
	    while used[v]
	    used[v] = 1
	    ds:584E[i] = v

`ds:584E` 是 0..25 的隨機排列，**每次進控制室重抽**。

#### 編碼（`sub_1D1FC`，`0x1D1FC`）

	if (ds:482B[c] & 1) return 'A' + ds:584E[c - 'A']    ; 大寫
	if (ds:482B[c] & 2) return 'a' + ds:584E[c - 'a']    ; 小寫
	return c                                             ; 其餘原樣

`ds:482B` 是 C runtime 的 ctype 表（bit 0 ＝ 大寫、bit 1 ＝ 小寫）。
程式碼裡寫的是 `ds:580D[c]` 與 `ds:57ED[c]`，而 `0x580D + 'A'` 與
`0x57ED + 'a'` 都等於 `0x584E` —— 兩條路查的是同一張表，
差別只在還原時加 `'A'` 還是 `'a'`。**大小寫會被保留**，所以答案的形狀固定是
一個大寫加七個小寫。

`sub_1D236`（`0x1D236`）就是「把整串字元逐個過 `sub_1D1FC` 再印出來」，
四行密文用的是它。

#### 玩法

畫面同時出現四行密文與 `Answer= Preamble Code=`。密文的明文是
`str.302`–`str.305`：

	We, the people of Terra, in order to
	form a more perfect union, establish
	justice, insure domestic tranquility,
	provide for the common defense...

玩家要認出這是美國憲法序言的改寫、由此推出字母對應，再把 `Preamble`
用同一張表編碼、打出那八個字元。**題目給的是要編碼的詞，不是要解的密文**。

#### 輸入與計時（`sub_1D11A` ＋ `sub_1D098` ＋ `sub_1CF78`）

輸入框畫在 (28, 22)–(38, 22)，最多 **8 個字元**（`0x20`–`0x7E`），
支援退格（`8` 或 `0xF0`）與 Esc（清空並回傳長度 0）。

每一次輪詢做四件事：非阻塞讀鍵、印計時器、把 `ds:0436:0438` 減 `0x4B`（75）、
沒按鍵就印一格轉輪並延遲 `0x32`。轉輪的八個字元在 `ds:050A`
（`1C 1D 05 1F 1C 1D 05 1F`），索引在 `ds:0512`。

計時器的顯示由 `sub_1CF78`（`0x1CF78`）做：值 ÷ 60000 → 分、餘 ÷ 1000 → 秒、
餘 ÷ 10 → 百分秒，三段都補零到兩位，中間用 `:` 隔開。
起始值 900,000 因此顯示成 **`15:00:00`**。歸零時 `sub_1D098` 直接把按鍵值
塞成 `0x0D`（Enter）強制送出。

	每輪扣 75、延遲 0x32 —— 實際牆鐘長度取決於延遲常式（root 0x11C66）的單位，
	未證實。畫面上跑的是 15 分鐘。

#### 判定（`sub_1D262`，`0x1D262`）

| 回傳 | 條件 |
|---|---|
| 2 | `ds:0436:0438 == 0`（時間到）|
| 1 | 長度正好 8 **且** 與 `ds:58AE` 逐字元相同 |
| 0 | 其餘 |

回傳 0 就回去重新輸入 —— **打錯不罰、可以一直試到時間用完**。
`Incorrect!` 只給第 3.2 節那兩道前置關卡用。

### 3.4 通關

	for di in 0..ds:0426-1:
	    si = 角色記錄
	    if (!(si[+129] & 8)) { si[+129] |= 8; si[+98] += 0x02FAF080; }
	    總分 += si[+98]                       ; 32 位元累加
	重畫 endgame.16
	印 ds:5868 十一行（第 15 欄，第 1–11 列）
	印 ds:587E 十行（第 1 欄，第 13–22 列）
	印 ds:0410 於 (13, 13)、ds:0412 於 (25, 13)   ; 勝場／敗場
	印 總分 於 (21, 14)
	換掉調色盤、播 ds:033E、跑一段十二格的循環動畫，按任意鍵結束
	ds:0395 = 2

`+129` bit 3 是「獎勵已領」，`0x02FAF080` ＝ **50,000,000 經驗值**，
角色記錄 `+98` 是經驗值（uint32）。旗標先檢查再設，所以重複通關不會重複給。

`ds:0410`／`ds:0412` 是戰鬥勝場與敗場，由 `2COMBAT` 各自 `inc`。
它們填進 `str.317` `'   Battles:       won /       lost.'` 的兩處空白，
座標 (13, 13) 與 (25, 13) 正好落在 `won`／`lost.` 前面。

**最終分數 ＝ 全隊經驗值總和**（含剛加上去的每人 5,000 萬），
填進 `str.318` `'Your final score is'` 那一行。

### 3.5 失敗與逾時

失敗分支（`loc_1D7E8`）印 `Incorrect!` 於 (15, 22)、停 200，然後
`ds:0394 = ds:0393 = 0`、`loc_172A6()`（2PLAY `+B75E`）、`ds:0430 = 7`、
`loc_172D6()`（2PLAY `+A580`），`ds:03CE == 1` 時再 `loc_17246()`（2PLAY `+B862`）。

逾時只設 `ds:0395 = 3` 就離開，由 `2PLAY` 呼叫 `loc_171E6`（root `0x13FD8`）。

兩條路最後都會合到 `loc_1D830`：釋放 `endgame.16`、把計時器歸零。

## 4. 版面座標

`loc_16F2E(欄, 列)`（root `0x11676`）寫的是繪圖狀態的 `+4`／`+5`；
`loc_1777A`／`loc_17786` 分別讀回這兩格。欄列的分工由「十四行訊息的變動值是
第二個參數」定出來，並與下表每一項互相印證：

| 內容 | 欄 | 列 |
|---|---|---|
| 守門旁白（4 行）| 1 | 19–22 |
| 中止碼提問（4 行）| 1 | 17–20 |
| 中止碼輸入（10 格）| 1 | 21 |
| Sheltem 預錄訊息（14 行）| 1 | 2–15 |
| 密文（4 行）| 1 | 17–20 |
| `Answer= Preamble     Code=` | 1 | 22 |
| 密碼輸入框 | 28–38 | 22 |
| 賀詞（11 行）| 15 | 1–11 |
| 戰績與分數（10 行）| 1 | 13–22 |

`Answer= Preamble     Code=` 長 26 個字元，佔第 1–26 欄，輸入框從第 28 欄起
——這一項是版面自洽的最硬證據。

## 6. 未解

- **`ds:0509` 的設定端**（見 §2）。DGROUP 初值非零，`2BRAIN` 會清零，
  但沒找到把它設回非零的地方。等級：未知。
- **`ds:58B8` 印在載入之前。** `_2smith_e01` 在第 19–22 列印 `ds:58B8`
  四格指標，而填這四格的 `sub_1D2A4` 要到同一支函式的結尾才被呼叫；
  `ds:58B8`–`ds:58BF` 在 DGROUP 初值段是 0，`58B8h` 這個字面值在 14 份 `.asm`
  裡只出現這兩處，而 `2PLAY` 的 `0xFD` 分支一次事件只呼叫 `_2smith_e01` 一次。
  四項合起來指向「第一次進控制室時那四行守門旁白印的是 `ds:0000`
  （`F9 C3 "Version 1.01"`），要到下一次進來才會正確顯示」。
  等級：**強推論** —— 靜態面四項都查過，缺的是實機。
  驗收方式：DOSBox 走到 `0e fd` 的格子，比對第一次與第二次進入時第 19–22 列的內容。
  指標間接寫入不會留下 `58B8h` 字面值，這條路沒有排除。
- `ds:58B6`（通關前被清成 0）、`ds:0430 = 7`、`loc_17042`（root `0x156C6`）
  與 `loc_1704E`（root `0x12734`）的語意。
- 計時器每輪扣 75、延遲 `0x32` 對應的實際秒數。

## 7. remake 的缺口

`internal/` 目前沒有控制室：`Sheltem` 只出現在 `MONSTERS.DAT` 的解析測試裡。
要接的話有一個設計問題要先決定 —— **這道密碼題翻成中文就解不開了**，
和 `KEYS`／`DRUIDS`／`MEENU` 那幾題同一類（見
[`../formats/07-event-script.md`](../formats/07-event-script.md) §謎題）：
密文是英文字母的替代加密，明文是美國憲法序言的改寫，
而中文玩家既認不出那段序言，也沒有字母可以代換。
