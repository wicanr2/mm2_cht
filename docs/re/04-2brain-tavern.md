# 酒館：`2BRAIN` 的第三個入口

輸入檔：`MM2.EXE` ＋ `2BRAIN.OVL`。IDA 位址取自 `workplace/ida/out/2BRAIN.asm`。

`2BRAIN` 有三個入口，事件腳本的 `0x0e` 各自對到一個：

| 代碼 | 進入點 | 內容 |
|---|---|---|
| `0e 03` | `_2brain_e02`（`+D15A`）| **酒館** |
| `0e 07` | `_2brain_e01`（`+C7E2`）| 大腦淨化 |
| `0e 08` | `_2brain_e00`（`+C130`）| 競技賽，見 [`08-combat.md`](../formats/08-combat.md) |

酒館與競技賽是**兩個不同的入口**。酒館那支呼叫五個選單項的函式，
裡面沒有競技賽 —— 它函式裡出現的 `Gladiator` 是稱號表的一格
（`ds:00FD`，前一格是 `Gambler`），不是入口。

## 選單

畫面是 `Select (A-E)` 五項，各對一支函式：

| 項 | 函式 | 內容 |
|---|---|---|
| A | `sub_1CB08` | **請全隊喝一輪**：價格 `ds:4226[地圖]` ＝ `[20, 250, 40, 120, 40]`；付得起就把每個隊員的食物（記錄 `+37`）補到 40 |
| B | `sub_1CB7C` | **點酒（`Buy (A-F)`）**：六種，價格 `ds:4230` ＝ `[5, 5, 20, 20, 50, 100]` |
| C | `sub_1CD60` | **點餐（`Buy (A-C)`）**：三種 |
| D | `sub_1CF74` | 狀況（記錄 `+38`）不為 0 就拒絕；付 1 金之後改記錄 `+115`（耐力）|
| E | `sub_1D038` | 未解 |

付款一律走 `sub_1CA8E(角色, 金額)`，訊息一律走 `sub_1C9FC(編號)`。

## 喝多了會出事

`sub_1CB7C` 選好之後：

1. `ds:5772[選項]` 是這個人**喝過幾杯**的計數。到達 `ds:423C[選項]`
   （門檻 `[2, 3, 3, 3, …]`）就呼叫 `sub_1C94E(記錄, 選項)`，並把記錄
   `+110` 減 2；還沒到就把計數加一。
2. 不論如何再擲一次：`修正 = 屬性修正(記錄 +115 耐力)`（`sub_1710E`，
   全遊戲共用的門檻表 `ds:4D84`），`rand(1, 修正 + 10)` 擲出 **2** 就呼叫
   `sub_17696(記錄)`。

也就是**耐力越高越不容易出事**。對應的台詞是 `str.dat` 的
`You feel sick!`、`Spoiled, You're sick!`、`An incredible meal!`。

## 訊息表在執行時才填

`sub_1C9FC` 印的是 `ds:5722` 那張指標表，而 `ds:5722` 在 DGROUP 初值段裡
**全是 0** —— 它由 `_2brain_e02` 開場的 `sub_17732` ＋ 七次 `loc_1773E`
從 `str.dat` 讀進來（`ds:0502` 指向 `str.dat`，與每日笑話同一支讀取器）。
落點是 `str.088` 起那一段，也就是五座城各自的酒保台詞
（`Amber, a sultry waitress`、`Belinthra, the bawdy proprietress`…）。

等級：選單分派、價格表、食物與醉酒判定**已證實**；
`sub_1CD60`（點餐）與 `sub_1D038` 的效果、以及七筆訊息各自對到 `str.dat`
的哪一筆，**未解**。

## 說明書講的「到神殿解除任務」

`2TEMPLE` 的字串只有 `Temple`／`has been healed.`／`is healthy.`／
`Select another character.` 與法師公會那一組，**沒有任何與任務有關的字**。
遊戲裡取消任務的實作是 Uncle Spudly 的藥水（腳本庫段 70 腳本 7，19 金，
清掉 `+120` 與 `+124` bit 2），見 [`../quests.md`](../quests.md) §2.6。

等級：**已證實**（掃過該 overlay 的全部字串）。說明書那句沒有對應的程式碼。
