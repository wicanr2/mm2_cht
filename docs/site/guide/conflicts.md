# 矛盾與勘誤

同一件事在不同地方講法不一樣的，全部列在這裡，**沒有偷偷挑一邊**。
會出現矛盾的原因有三種：雜誌自己前後期不一致、雜誌與說明書不一致、
雜誌與遊戲內訊息不一致。

哪一邊對，只有原版程式說了算。**沒有在原版上驗證過的，這裡就寫「未驗證」** ——
把兩種說法都留著，比挑一個看起來合理的寫進正文安全。

::: conflict

## 為什麼不直接刪掉錯的那一邊

這一頁看起來像是把雜項堆在一起，但它有明確的用途：

**照著攻略走卻走不通的時候，第一個要問的是「我看的這一條有沒有第二種說法」。**
最後地下城的座標寫錯一格，你會在 C2 的沙漠裡繞很久，而且完全不知道問題出在哪 ——
因為「這一格沒有入口」跟「我記錯了」在畫面上長得一模一樣。

同樣的道理，巫師塔的兩個數字左右順序如果搞反，你會以為是路線走錯，
回頭重走一次德魯伊給的十三道門。

## 已經解決的一條

雜誌自己更正過一次：第 006 期寫「利用飛毯（Fly Carpet）飛到 B3」，
第 008 期作者自行更正 —— **MM2 裡沒有魔毯**，移動手段是 Witch Broom 或巫師 3-2 法術。
巫師 3-2 是飛行術（Fly），這一條在原版的法術表上對得到，所以這條算結案，
攻略正文採用更正後的說法。

## 不屬於玩家提示的那一條

`ROSTER.DAT` 六個屬性欄的順序，雜誌第 010 期的檔案格式表寫「力量、人格、智慧、速度、
準確度、運氣」，而 remake 實測第 2、3 格是**智慧與人格**，與雜誌相反。

這一條沒有收進攻略，因為它是檔案格式的事，不是玩家用得到的提示。
本專案已在 `docs/formats/02-data-files.md` 判定以實測為準。列在這裡只是為了說明
**同一份雜誌在「玩法」與「資料結構」兩件事上的可靠度不一樣** ——
玩法是作者玩出來的，資料結構是他拿工具看出來的，後者更容易抄錯。
