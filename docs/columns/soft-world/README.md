# 《軟體世界》×《魔法門 II》考證專欄

這是可放進乾淨公開 GitHub repo 的**原創專欄**。它把 1989–1990 年代中文
攻略作為頁碼可追溯的線索，重新以本專案的 DOS oracle、資料解析與實測驗證，
而不是重印雜誌內容。

## 發布規則

- 只寫自行撰寫的導讀、摘要、驗證結果與勘誤；不放掃描、OCR 全文、原刊表格、
  地圖或可替代原文的長引文。
- 每個事實至少附期別與印刷頁；若沒有原版側的獨立證據，明確標為「待驗」。
- 「已證實」只用於有 DOS oracle、原版資料或可重跑程式證據的內容；雜誌內
  不同期的互相呼應仍只是同一個二手來源。
- 私有研究稿不隨公開版本發佈；公開匯出時必須排除該目錄和 `data/hints.json`，
  以 `tools/check_release.sh --public` 驗證。公開文章不得連到已排除的私有路徑。

## 新文章資料卡

每個新條目至少寫下：

1. 自己改寫的玩家問題或觀察；
2. 來源的期別／印刷頁（不複製原文）；
3. 證據等級：`已證實`、`待驗` 或 `已推翻`；
4. 獨立證據的檔案、測試或 DOS oracle 路線；
5. 對玩家的實際影響，以及有衝突時採取的處置。
