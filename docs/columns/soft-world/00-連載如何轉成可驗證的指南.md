# 從雜誌連載到可驗證的指南

1989 年的《軟體世界》曾連載《魔法門 II》攻略。這份專欄不把它當成不可質疑的
答案本，而是把每一期、每一頁視為一條待驗證的歷史線索：它告訴我們當時的玩家
如何理解世界、卡在哪裡，以及哪些說法值得回到 DOS 版重新測試。

## 連載的輪廓

目前已整理到第 006–010 期，涵蓋第二回至完結篇與修改資料；第一回所在的第 005
期仍待取得。第 006 期的 MM2 正文在印刷頁 40–45，第 007 期在 45–48，第 008
期在 28–30，第 009 期在 36–39，第 010 期則分布於 40–41 與 53–59。

這個頁碼表本身已經幫我們排除一項舊誤會：第 006 期緊接 MM2 單元的城市地圖，
實際屬於另一款遊戲，不能被拿來推導魔法門的城鎮結構。考證的第一步不是把資料
堆得更多，而是先確認每一頁真的屬於哪個作品。

## 攻略不是規則書

雜誌攻略可保存當時的路線、傳言與玩家經驗，但它可能有誤植、平台差異或省略的
前置條件。因此本專欄把內容分成三類：

- **已證實**：已由 DOS 原版行為、原始資料或可重跑的解析結果獨立支持。
- **待驗**：目前只有雜誌來源；會保留頁碼，但不把它寫成引擎規則。
- **已推翻**：後來的原版證據與說法衝突；說明衝突的原因，而不是悄悄刪除。

這套標記讓讀者同時看見兩種歷史：當年的中文攻略怎麼引導玩家，以及今天的
remake 能夠以哪些證據重現或修正它。

## 接下來會寫什麼

後續文章會以「玩家能否採取某個行動」為單位，例如一條設施路線、一個迷題、
一段地圖移動或一種物品效果。每篇先交代來源頁碼，再列出實測結果與尚未確認的
限制；不重製原刊地圖或表格。這樣即使讀者沒有接觸私有研究稿，也能理解結論的
證據邊界。
