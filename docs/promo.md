# 《魔法門 II》繁中 remake 推廣片

推廣片是由目前引擎的實際 UI 畫面重拍，不使用另外繪製的假介面。因影片會顯示
玩家自備原版資料所解出的 DOS／Amiga／MSX 素材，輸出只放在已忽略的
`workplace/promo/`，不得直接提交、推送或上傳。公開版本必須先取得素材公開許可，
或把畫面全部換成可再散布的原創 Theme。

## 60 秒分鏡

| 時間 | 畫面 | 重點 |
|---|---|---|
| 0–5 秒 | 繁中標題與神殿對話 | 1988 年 CRPG 的可玩繁中 remake |
| 5–20 秒 | 同一座走廊依序切 DOS、Amiga、MSX、Modern | 同一引擎、完整素材組原子切換 |
| 20–35 秒 | 建角、物品、商店 | 玩家日常操作與繁中排版 |
| 35–48 秒 | 施法、戰鬥、防護 | 規則與戰術介面 |
| 48–56 秒 | 地圖、說明書、世界地圖 | 紙本資訊整合進遊戲 |
| 56–60 秒 | Logo 與玩家自備合法原版提示 | 發行邊界 |

功能畫面只有在正常 UI 垂直鏈通過後才可放入本輪成片。測試直接注入的寶箱畫面不得
冒充玩家正常可達；一般寶箱入口完成前，成片以地圖或說明書畫面替代。

## 新配樂與權利紀錄

- 名稱：〈異界之門：五步〉。
- 性質：2026-08-12 為本 remake 推廣片新作，不是原版未發表配樂，也沒有改編原版旋律。
- 動機：D–F–A–G–E，五個音對應探索、警戒、戰鬥、回望與未解的出口。
- 聲音：FFmpeg 內建 `sine`／`aevalsrc` 合成，不依賴 SoundFont、取樣庫或第三方生成服務。
- 形式：60 秒線性 cue；前段低密度，中段加入脈衝，結尾保留未完全解決的五度。
- 權利：由專案腳本參數生成；可隨引擎原始碼重製。影片中的原版衍生視覺仍受上述
  本機限制，音樂可公開不代表畫面可公開。

## 重拍

```bash
bash tools/render_promo.sh --data-dir /path/to/MM2
```

腳本只在 Docker 內執行 Go、截圖與 FFmpeg。預設輸出：

```text
workplace/promo/mm2-remake-trailer.mp4
workplace/promo/shots/*.png
```

完成後需人工觀看，確認中文沒有裁切、Theme 標示與實際畫面一致、施法畫面確實來自
正常 UI，以及音樂沒有蓋過未來可能加入的遊戲音效。技術上可解碼不等於完成觀賞驗收。
